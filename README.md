# Lëtzebuergesch Flashcards — A2

A phone-first flashcard web app for learners working through the **Schwätzt Dir Lëtzebuergesch? A2**
course book. Pick the book pages you want to study, choose which kinds of words to include, and the
answer language(s) — then flip through cards.

- **Page-range selector** (study just the pages you're on, e.g. 10–64)
- **Word-type toggles** (text & dialogue, questions, titles, illustrations, vocabulary, grammar…)
- **Answer language(s):** German, French, English, Portuguese, Dutch
- iPhone-optimized, installable (PWA), works offline after first load

Translations, IPA and example sentences are from the **Lëtzebuerger Online Dictionnaire**
([lod.lu](https://lod.lu)), public domain (CC0). No personal data is collected; settings live only
in your browser. Static site — just HTML/CSS/JS, no build step.
