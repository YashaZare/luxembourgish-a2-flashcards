# Lux Vocab Icon Pack

Stroke-based icon assets for a Luxembourgish vocabulary learning app.

## Contents

- `svg/light` and `svg/dark`: 24px transparent SVG masters.
- `png/<theme>/1x`: 24x24 transparent PNG, with a same-name SVG beside each PNG.
- `png/<theme>/2x`: 48x48 transparent PNG, with a same-name SVG beside each PNG.
- `png/<theme>/3x`: 72x72 transparent PNG, with a same-name SVG beside each PNG.
- `preview/icon-sheet.png`: side-by-side light and dark preview.

## Palettes

- Light cream: ink `#26312D`, secondary `#5F6C66`, accent `#73BDA6`.
- Dark tactile: ink `#F0E7D8`, secondary `#A99A8A`, accent `#D86B3E`.
